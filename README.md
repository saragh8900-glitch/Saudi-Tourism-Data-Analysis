# Saudi Tourism Dashboard

Project Overview

This project focuses on analyzing tourism establishments in Saudi Arabia using Microsoft Power BI. The dashboard presents tourism-related data through interactive visualizations to help users understand the tourism sector and explore key statistics.

## Data Source

The dataset is based on the Tourism Establishments Statistics for Q2 2026, published by the General Authority for Statistics (GASTAT) in Saudi Arabia.

## Tools Used
 • Microsoft Power BI
 • Microsoft Excel

## Key Features
 • Visualization of tourism establishments statistics.
 • Analysis of hotel-related data.
 • Exploration of Saudi participation in the tourism sector.
 • Interactive charts and data visualizations.
 • Clear presentation of key tourism indicators.

## Project Objective

The objective of this project is to transform raw tourism data into meaningful visual insights through data cleaning, analysis, and dashboard design
